# PRAPURA Trial 2

A separate experimental version of the PRAPURA static website. The fixed Kannada elephant-skin texture remains as the page background. The site follows the visitor’s device light/dark preference by default and includes a circular symbolic theme switch; a chosen theme is saved locally in that browser. Existing site content is retained.

## Preview locally
Open `index.html` in a browser. For best testing, run a local static server or use GitHub Pages.

## Publish
Copy the contents of this folder into a separate branch or directory for testing. Keep your existing `CNAME` unless you intentionally want to change the live domain.


## Trial 2 — Single dark theme

This version uses the selected teal-and-gold PRAPURA logo and the fixed Kannada elephant-skin background throughout the page. It uses one polished dark theme, translucent surfaces, and a more readable type scale. The theme switch is intentionally removed. Test locally before deploying to GitHub Pages.
